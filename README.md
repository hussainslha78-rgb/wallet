# تطبيق الموبايل — «المحفظة» و«بيتنا»

الفولدر ده بيخلّي التطبيق يتثبت على الموبايل كأنه برنامج: أيقونة على الشاشة الرئيسية، يفتح بملء الشاشة من غير شريط المتصفح، وإشعارات حقيقية.

| الرابط | التطبيق |
|---|---|
| `https://اسمك.github.io/wallet/` | «المحفظة» (ليك) |
| `https://اسمك.github.io/wallet/bayt/#k=…` | «بيتنا» (لغادة — الرابط الكامل بتنسخه من التطبيق) |

## 1) ارفعه على GitHub Pages (مرة واحدة)
1. github.com ← اعمل حساب (الأحسن حساب مخصوص للتطبيق ده — شوف «الأمان» تحت).
2. **New repository** ← الاسم `wallet` ← **Public** ← Create.
3. **Add file ← Upload files** ← اسحب **كل اللي جوّه فولدر phone-app** (الملفات وفولدر `icons` وفولدر `bayt`) ← **Commit changes**.
4. **Settings ← Pages** ← Source: **Deploy from a branch** ← Branch: `main` و `/ (root)` ← **Save**.
5. بعد دقيقة الرابط بيبقى `https://اسمك.github.io/wallet/`.

## 2) حط لينك التطبيق في config.js
افتح `config.js` على GitHub ← ✏️ ← حط لينك `/exec` (من Apps Script ← Deploy ← Manage deployments ← Web app URL) ← **Commit changes**.

- لو عدّلت نفس الـ Deployment (✏️ ← New version): مش محتاج تغيّر حاجة.
- لو عملت **New deployment** (لينك جديد): غيّر السطر ده بس.

## 3) قول للتطبيق على الرابط
افتح التطبيق عادي ← الإعدادات ← **🔔 الإشعارات** ← «رابط تطبيق الموبايل» = `https://اسمك.github.io/wallet/` ← حفظ.
التطبيق مش هيكلّم ولا هيصدّق غير الصفحة دي.

## 4) على موبايلك (S25)
1. افتح `https://اسمك.github.io/wallet/` في **Chrome** ← ⋮ ← **تثبيت التطبيق** (أو «إضافة إلى الشاشة الرئيسية»).
2. افتحه من الأيقونة ← اكتب الرمز مرة واحدة (بعد كده بيفتح لوحده).
3. الإعدادات ← 🔔 الإشعارات ← **فعّل الإشعارات هنا** ← **اسمح** ← **جرّب إشعار**.

## 5) غادة
من 🔔 الإشعارات ← **انسخ رابط غادة** وابعته ليها هي بس (فيه مفتاحها).
- **آيفون:** تفتحه في **سفاري** ← زرار المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية** ← وتفتح التطبيق **من الأيقونة** (الإشعارات على آيفون محتاجة iOS 16.4 أو أحدث، ومابتشتغلش غير من الأيقونة).
- **أندرويد:** Chrome ← ⋮ ← تثبيت التطبيق.
- أول ما تفتحه هيظهرلها كارت «🔔 خلّي الإشعارات توصلك» ← «فعّلي الإشعارات» ← اسمح.

## الأمان
- الريبو Public (ده شرط GitHub Pages المجاني) — عشان كده `config.js` فيه لينك `/exec` بس. **ماتحطش فيه `?k=` ولا أي كود.** اللينك لوحده مابيفتحش حاجة: «المحفظة» بتعرفك من حساب جوجل، و«بيتنا» محتاجة مفتاحها.
- رمز الدخول ومفتاح غادة بيتحفظوا على الموبايل نفسه بس (في صفحة GitHub). كل صفحات GitHub Pages اللي على نفس الحساب بتشارك التخزين ده — عشان كده الأحسن حساب GitHub مخصوص مافيهوش أي صفحات تانية.
- لو حد خد موبايلك وهو مفتوح يقدر يفتح التطبيق من غير الرمز (لأنه محفوظ). لو عايز تمسحه: إعدادات Chrome ← الخصوصية ← امسح بيانات الموقع `github.io`.

## لو حاجة مش شغالة
- **شاشة بيضا / «لصاحب الحساب بس»:** «المحفظة» بتعرفك من حساب جوجل اللي فاتح بيه Chrome. افتح التطبيق مرة في Chrome عادي وانت عامل تسجيل دخول بحساب جوجل بتاعك، وارجع للأيقونة. لو لسه: Chrome ← الإعدادات ← إعدادات المواقع ← ملفات تعريف الارتباط التابعة لجهات خارجية ← اسمح بيها (أو ضيف `github.io` في المسموح). ثبّته من **Chrome** مش من متصفح سامسونج.
- **الإشعارات مش بتيجي:** 🔔 الإشعارات ← «جرّب إشعار». لو ماوصلش: شيل الجهاز من «الأجهزة اللي بيوصلها» وفعّلها تاني.
- **اسم تطبيق غادة:** لو اسم تطبيقها مش «بيتنا»، غيّر `name` و `short_name` في `bayt/manifest.webmanifest` و`<title>` في `bayt/index.html`.
